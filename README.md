# Stardw — 2D Пиксельная RPG / Песочница на Godot 4.7

Полноценный проект на **Godot 4.7** в классическом 16-битном пиксель-арт стиле (тайлы `16×16 px`, спрайт персонажа `32×32 px`, масштабирование камеры `3.5x`) с процедурным миром, коллизиями и 8-направленными анимациями персонажа.

---

## Что реализовано

### 1. Сгенерированные пиксельные ассеты (`tools/generate_assets.py` → `assets/`)
Все ассеты генерируются детерминированным скриптом `tools/generate_assets.py` (чистый Python без внешних зависимостей):
- **`assets/sprites/player_spritesheet.png` (`192×1792 px`)** — 56 рядов × 6 кадров (`32×32 px` на кадр):
  - **7 состояний анимации** × **8 направлений** = **56 анимаций**.
- **`assets/sprites/player_8dir_showcase.png` (`512×448 px`)** — наглядная таблица всех 8 направлений и 7 анимаций.
- **`assets/tilesets/world_tileset.png` (`256×80 px`)** — тайлсет мира `16×16 px` (глубокая вода, мелководье, течение реки, кувшинки, песчаный берег, луговая и лесная трава, тропинки, деревянные мосты, политая почва, цветы, грибы, камешки).
- **`assets/objects/*.png`** — объекты окружения с прозрачным фоном для Y-Sort сортировки:
  - Дуб (`tree_oak.png`), Ель (`tree_pine.png`), Берёза (`tree_birch.png`), Пень (`tree_stump.png`), Куст с ягодами (`bush_berry.png`), Поваленное бревно (`log_fallen.png`), Большой валун (`rock_large.png`), Камень (`rock_small.png`), Рудная жила (`rock_ore.png`).
- **`assets/ui/*.png`** — иконки инструментов хотбара (`icon_axe.png`, `icon_pickaxe.png`, `icon_water.png`, `icon_hand.png`) и иконка проекта `icon.png`.

### 2. Ходьба, бег и различные анимации персонажа (`scripts/player.gd`, `scenes/player.tscn`)
- **7 состояний анимаций** (каждое по всем 8 направлениям):
  1. `idle` — покой (дыхание, моргание)
  2. `walk` — плавный шаг (6 кадров)
  3. `run` — динамичный бег по `Shift` с наклоном корпуса, развевающимся шарфом и частицами пыли (6 кадров)
  4. `axe` — рубка топором со следом взмаха и щепками (6 кадров)
  5. `pickaxe` — удар киркой с искрами (6 кадров)
  6. `water` — полив из лейки с анимированными каплями воды (6 кадров)
  7. `interact` — взаимодействие / сбор ягод / эмоция (4 кадра)
- Настроены `AnimationPlayer` (56 анимаций в `AnimationLibrary`) и `AnimationTree` (`AnimationNodeStateMachine` + `AnimationNodeBlendSpace2D` по 8 векторам).

### 3. Анимация и движение по всем 8 осям и углам
- Полная поддержка 8 направлений с нормализацией диагонального вектора и буфером плавного отпускания диагональных клавиш (`DIAGONAL_GRACE_TIME`):
  - `down` (Юг — Вниз)
  - `down_right` (Юго-Восток — Вниз-Вправо)
  - `right` (Восток — Вправо)
  - `up_right` (Северо-Восток — Вверх-Вправо)
  - `up` (Север — Вверх)
  - `up_left` (Северо-Запад — Вверх-Влево)
  - `left` (Запад — Влево)
  - `down_left` (Юго-Запад — Вниз-Влево)

### 4. Процедурный мир с лесом, реками и озёрами (`scripts/world.gd`, `scenes/world.tscn`)
- Генерация на базе трёх слоёв `FastNoiseLite` по сиду (`world_seed`):
  - **Озёра** с глубоководьем, мелководьем, кувшинками и песчаными пляжами.
  - **Извилистые реки** с анимацией течения и автоматическими **деревянными мостами** на пересечении с тропинками.
  - **Лесные биомы** (дубовые, сосновые и берёзовые рощи, ягодные кусты, грибные поляны, поваленные брёвна) и **каменистые выходы руды**.
- Включена глубина **`y_sort_enabled = true`**: персонаж ходит как перед деревьями, так и за их кронами.

### 5. Коллизии (`TileSet Physics Layer` + `StaticBody2D` + `CharacterBody2D`)
- **Коллизии воды и рек**: физический слой `physics_layer_0` в `TileSet` блокирует выход в реки и озёра, но позволяет свободно переходить реки по деревянным мостам.
- **Коллизии объектов леса**: каждое дерево, валун, камень, пень, бревно и куст имеет `StaticBody2D` с `CollisionShape2D` у основания ствола.
- **Коллизия персонажа**: круглая форма `CircleShape2D` в области ступней (`Vector2(0, 10)`, `radius = 5.0`), позволяющая мягко скользить вдоль диагональных берегов и деревьев без застревания.
- **Отладка коллизий (`[C]` / `[F3]`)**: визуализирует прямо в игре коллизии берегов/воды, стволов деревьев, камней, хитбокс ног персонажа и вектор направления по 8 осям.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / `Стрелки` | Ходьба по 8 направлениям (включая все диагонали) |
| `Shift` (удерживать) | Бег (`run`) |
| `Пробел` / `ЛКМ` | Использовать выбранный инструмент (`axe`, `pickaxe`, `water`, `interact`) |
| `E` / `F` | Взаимодействие / сбор (`interact`) |
| `1`, `2`, `3`, `4` / Колесо мыши | Выбор инструмента (Топор, Кирка, Лейка, Рука) |
| `R` | Сгенерировать новый процедурный мир (новый сид) |
| `C` / `F3` | Включить / выключить визуализацию всех коллизий и 8-осевого луча |

## Запуск в Godot 4.7

1. Откройте **Godot 4.7** → **Import** → выберите файл `project.godot` в корне репозитория.
2. Нажмите **F5 (Run Project)** — запустится главная сцена `res://scenes/main.tscn`.
3. Для перегенерации PNG-ассетов при необходимости выполните:
   ```bash
   python3 tools/generate_assets.py
   ```
