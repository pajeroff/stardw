# Stardw — 2D изометрическая RPG на Godot 4.7

Изометрическая 2:1 проекция (`64×32 px` на верхнюю грань, `64×40 px` на ячейку с фаской), процедурный лес с рекой и озёрами, природные объекты и исследователь с 8 направлениями движения. Обновлённая графика и анимации выполнены в тёплом, уютном пиксель-арт духе Stardew Valley.

## Графика и ресурсы

### Персонаж — `assets/sprites/player_spritesheet.png`
- Спрайт-лист `1536×5376 px`: 56 рядов × 16 кадров `96×96 px`.
- Восемь направлений и семь состояний: `idle`, `walk`, `run`, `axe`, `pickaxe`, `water`, `interact`.
- Для персонажа перегенерированы ИИ пять ракурсов спокойной позы (`assets/ai_raw/ai_character_*.png`); недостающие направления отражаются по горизонтали.
- В спокойствии, ходьбе и беге теперь по 16 кадров на каждое из 8 направлений; частота кадров удвоена, чтобы сохранить прежнюю длительность циклов и сделать движение плавнее.
- Высота персонажа в кадре — до `74 px`. Детализация и полупрозрачные края сохраняются Lanczos-фильтрацией.
- Витрина ракурсов и состояний: `assets/sprites/player_8dir_showcase.png` (`768×672 px`).

### Изометрический тайлсет — `assets/tilesets/world_tileset.png`
- Атлас `1024×200 px` с неизменной раскладкой `16×5` ячеек `64×40 px`, используемой `scripts/world.gd`.
- Для травы и воды в атлас интегрированы новые ИИ-сгенерированные бесшовные текстуры `assets/ai_raw/ai_meadow_texture.png` и `assets/ai_raw/ai_water_texture.png`; палитра подгоняется к типу поверхности.
- Трава, клевер, песок, камень, мост, почва, вода, лилии и природные декорации собираются с 4× суперсэмплингом. Варианты водных тайлов продолжают использоваться для анимации волн.

### 19 объектов мира — `assets/objects/`
- 8 видов деревьев, 8 разновидностей камней без руды и 3 лесных объекта (пень, ягодный куст, поваленное бревно).
- Спрайты формируются из исходных иллюстраций в `assets/ai_raw/`, с мягкой фильтрацией и полупрозрачной тенью.

## Пересборка графики

Из корня проекта:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/build_isometric_assets.py
```

Генератор сохраняет совместимость с раскладкой атласа; фильтрация персонажа, объектов и слоёв тайлов настроена на сглаживание.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / `Стрелки` | Ходьба по 8 изометрическим направлениям |
| `Shift` | Бег |
| `Пробел` / `ЛКМ` | Использовать выбранный инструмент |
| `1` / `2` / `3` / `4` | Топор / кирка / лейка / сбор и осмотр |
| `E` / `F` | Сбор или осмотр |
| `R` | Сгенерировать мир с новым сидом |
| `C` / `F3` | Показать или скрыть коллизии |
| `F11` | Переключить полноэкранный режим |
