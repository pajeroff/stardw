# Stardw — 2D Изометрическая HD Pixel-Art RPG на Godot 4.7

Полноценный проект на **Godot 4.7** с **изометрической 2:1 проекцией** (`TILE_SHAPE_ISOMETRIC`, ромбовидные тайлы `64×32 px` с 3D-фаской `64×40 px`) и детализированными **ИИ-сгенерированными пиксель-арт ассетами высокого разрешения** (персонаж-путешественник `96×96 px` на кадр, деревья `144×192` / `168×176 px`, камни и руда до `112×96 px`).

---

## Что реализовано

### 1. ИИ-сгенерированные HD Pixel-Art ассеты (`assets/ai_raw/` → `tools/build_isometric_assets.py` → `assets/`)
- **Персонаж-Путешественник (`assets/sprites/player_spritesheet.png`, `576×5376 px`, `96×96 px` на кадр)**:
  - Сгенерирован через ИИ в 32-битном HD пиксель-арт стиле (плащ следопыта с капюшоном, кожаный походный рюкзак со спальником и фонарём, посох странника, высокие сапоги).
  - Собрана полная таблица из **56 анимаций** (8 изометрических направлений × 7 состояний: `idle`, `walk`, `run`, `axe`, `pickaxe`, `water`, `interact`).
  - Наглядная витрина всех 8 осей и 7 анимаций: **`assets/sprites/player_8dir_showcase.png` (`768×672 px`)**.
- **Разновидности изометрических деревьев (`assets/objects/`)**:
  - `tree_oak.png` (`160×176 px`) — древний раскидистый дуб с корнями
  - `tree_willow.png` (`168×176 px`) — плакучая прибрежная ива со свисающей листвой
  - `tree_pine.png` (`144×192 px`) — высокая северная ель
  - `tree_birch.png` (`144×176 px`) — белоствольная золотисто-зелёная берёза
  - `tree_stump.png` (`64×56 px`) — срубленный пень с годовыми кольцами
  - `log_fallen.png` (`96×56 px`) — замшелое поваленное бревно с лесными грибами
  - `bush_berry.png` (`68×60 px`) — густой лесной куст с красными ягодами
- **Разновидности камней и руды (`assets/objects/`)**:
  - `rock_large.png` (`112×96 px`) — крупный гранитный валун, поросший мхом и папоротником
  - `rock_slate.png` (`112×96 px`) — ступенчатая тёмная сланцевая скала
  - `rock_ore.png` (`88×76 px`) — рудная порода с золотисто-янтарными кристаллами
  - `rock_small.png` (`64×56 px`) — малый полевой камень
- **Изометрический тайлсет (`assets/tilesets/world_tileset.png`, `1024×200 px`, ячейки `64×40 px`)**:
  - Вода: глубокие озёра, бирюзовое мелководье, речное течение, кувшинки с лотосами.
  - Разновидности земли и травы: песчаный берег с галькой, солнечная луговая трава, тёмный изумрудный лесной мох, золотистая осенняя трава берёзовой рощи, скальный сланец, мощёная камнем дорога странника, деревянные изометрические мосты и политая почва.

---

### 2. Изометрическая графика и генерация мира (`scripts/world.gd`, `scenes/world.tscn`)
- Настроена изометрическая сетка Godot 4 (`TileSet.TILE_SHAPE_ISOMETRIC`, `TileSet.TILE_LAYOUT_DIAMOND_DOWN`, `tile_size = Vector2i(64, 32)`).
- Процедурная генерация мира по сиду (`FastNoiseLite`):
  - Непрерывная извилистая река с 3 выровненными деревянными мостами и мощёными дорогами.
  - 2 живописных озера с глубоководьем, мелководьем, кувшинками и песчаными пляжами.
  - Прибрежные плакучие ивы у воды, сосновое высокогорье со сланцевыми скалами на севере, дубовые рощи на западе и золотая берёзовая роща на востоке.

---

### 3. Точные изометрические коллизии (`WaterBody` + `TileSet` + `WorldObject`)
- Все водные тайлы имеют ромбовидные изометрические полигоны коллизии (`CollisionPolygon2D` `64×32` ромб) как в физическом слое `TileSet`, так и в узле `WaterBody` (`StaticBody2D`).
- Все деревья, валуны, скалы, руда, брёвна и кусты имеют выверенные `RectangleShape2D` у основания и единую точку привязки `y_sort_enabled = true`.
- Нажатие **`C` / `F3`** отображает прямо в игре изометрические ромбы коллизий воды, хитбоксы стволов/камней, бокс ног путешественника и вектор направления по 8 осям.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / `Стрелки` | Ходьба по 8 изометрическим направлениям |
| `Shift` (удерживать) | Бег (`run`) |
| `Пробел` / `ЛКМ` | Использовать инструмент (`1` — Топор, `2` — Кирка, `3` — Фляга, `4` — Посох) |
| `E` / `F` | Действие посохом / сбор (`interact`) |
| `R` | Сгенерировать новый изометрический мир по новому сиду |
| `C` / `F3` | Показать / скрыть изометрические коллизии |
