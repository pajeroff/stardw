# STARDW — рыбацкая долина (Godot 4.7)

Изометрическая игра в духе **Stardew Valley**, где главный упор — **рыбалка**.
Вся графика (тайлы, персонажи, 38 видов рыб, предметы, UI, эффекты) и весь звук
(СФЗ + музыка) **генерируются процедурно** скриптами в `tools/` — в репозитории нет
ни одного скачанного арта.

## Запуск

1. Открой проект в **Godot 4.7** (File → Import Project → `project.godot`).
2. Нажми ▶ (главная сцена — `scenes/main_menu.tscn`).

Если ассеты отсутствуют, перегенерируй их:

```
python3 tools/gen_assets.py    # текстуры + assets/manifest.json + icon.svg
python3 tools/gen_audio.py     # assets/sfx/*.wav + assets/music/*.wav (numpy)
python3 tools/render_preview.py# docs/preview/ — арт-превью и пример сцены
```

## Что есть в игре

- **Изометрия**: ромбовидные тайлы 2:1 (`TileMapLayer` + iso-математика в `iso.gd`),
  y-sort для персонажа, деревьев и построек.
- **Рыбалка (ядро)**: заброс с поплавком, ожидание поклёвки, «!», и мини-игра
  «планка и рыба» в стиле Stardew с прогрессом, сокровищами и сложностью по видам.
- **38 видов рыб** (включая 6 легендарных) с сезонами, водоёмами (озеро/река/океан/пруд),
  временем суток и погодой; каталог рыб (F).
- **Снаряжение**: 4 удочки, наживки, поплавки/крючки/магнит, блесны — влияют на заброс,
  клёв и мини-игру. Магазин (покупка/продажа).
- **Цикл дня**: часы, смена сезонов и погоды (дождь/гроза/снег), день/ночь (тонировка),
  энергия, еда, сон, доска ежедневных заказов.
- **Прогресс**: золото, каталог, заказы, сохранение в `user://stardw_save.json`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| ПРОБЕЛ | заброс удочки / подсечка / удержание планки |
| E | взаимодействие (магазин, дом, доска, костёр) |
| F | каталог рыб |
| 1..0 | слоты инвентаря (еда съедается, снасть экипируется) |
| ESC | пауза |

## Проверка (без движка)

В песочнице нет бинаря Godot (загрузка релизов GitHub заблокирована прокси), поэтому
движковый прогон выполнить нельзя. Вместо этого:

- `gdparse` (gdtoolkit 4.5) — все 21 `.gd` файла парсятся без синтаксических ошибок;
- `tools/validate_project.py` — кросс-проверка ссылок: пути `preload/load`, имена в
  `manifest.json`, рыбы в БД ↔ арт, иконки, input-экшены, autoload'ы, границы атласов.
  Проходит: «OK — 21 scripts, 282 regions, 74 anims, 38 fish».

Запустить её: `python3 tools/validate_project.py`.
