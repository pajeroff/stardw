# Stardw — 2D Изометрическая RPG на Godot 4.7 (Smooth Pixel-Art)

Полноценный проект на **Godot 4.7** с **изометрической 2:1 проекцией** (`TILE_SHAPE_ISOMETRIC`, ромбовидные тайлы `64×32 px` с 3D-фаской `64×40 px`), мягкой сглаженной графикой (`pre-filtered Gaussian + LANCZOS` и `TEXTURE_FILTER_LINEAR` без режущих глаз пикселей), **19 разновидностями природных деревьев, камней (без руды) и объектов леса** и плавными **8-кадровыми анимациями** персонажа-исследователя без экипировки.

---

## Что реализовано и обновлено

### 1. Персонаж-Исследователь без какой-либо экипировки (`assets/sprites/player_spritesheet.png`, `768×5376 px`)
- **Внешний вид**: Обычный путешественник-исследователь в простой походной одежде (светлая рубашка с закатанными рукавами, кожаный жилет, оливковые брюки, кожаные сапоги) — **без посоха, без рюкзака, без оружия и без какой-либо экипировки на всех кадрах**.
- **Все 8 честных ракурсов (`45°`)**:
  - Юг (`explorer_south.png`), Юго-Восток / Юго-Запад (`explorer_front.png`), Восток / Запад (`explorer_side_stand.png`), Северо-Восток / Северо-Запад (`explorer_back.png`), Север (`explorer_diag_up.png`).
- **Плавные $C^\infty$ 8-кадровые анимации (56 рядов × 8 кадров `96×96 px`)**:
  - Все 7 состояний (`idle`, `walk`, `run`, `axe`, `pickaxe`, `water`, `interact`) используют гладкие гармонические кривые (`sin²(phase)` без резких изломов `|sin|` и с колоколообразной огибающей `sin²(πt)` для одиночных действий).
  - В `scripts/player.gd` при смене направления во время ходьбы или бега сохраняется текущая фаза анимации (`anim_player.seek`), поэтому при поворотах персонаж не дёргается на 0-й кадр.
- **Витрина всех направлений и состояний**: `assets/sprites/player_8dir_showcase.png` (`768×672 px`).

### 3. Мягкий сглаженный пиксель-арт без резких пикселей (`tools/build_isometric_assets.py`, `project.godot`)
- Все спрайты проходят предварительную низкочастотную гауссову фильтрацию (`smooth_prefiltered_resize`) перед уменьшением с `LANCZOS`, что полностью убирает «лесенки» и резкий звон пикселей (`ringing`).
- Изометрический тайлсет (`assets/tilesets/world_tileset.png`, `1024×200 px`, 5 рядов × 16 колонок) рендерится с **4× суперсэмплингом** (`256×160 → 64×40 px`) и согласованными по цвету боковыми гранями без тёмных сеточных швов.
- В `project.godot` и во всех сценах (`player.tscn`, `world_object.tscn`, `world.tscn`) включена линейная фильтрация текстур (`default_texture_filter=1`, `texture_filter = 2`) и плавное субпиксельное движение.

## Управление в Godot 4.7

| Клавиша | Действие |
|---|---|
| `WASD` / `Стрелки` | Ходьба по 8 изометрическим направлениям |
| `Shift` (удерживать) | Бег (`run`) |
| `Пробел` / `ЛКМ` | Действие (`1` — Рубка дерева, `2` — Разбор камня, `3` — Полив почвы, `4` — Сбор) |
| `E` / `F` | Действие сбора / осмотра (`interact`) |
| `R` | Сгенерировать новый изометрический мир по новому сиду |
| `C` / `F3` | Показать / скрыть изометрические коллизии воды, деревьев, камней и персонажа |
