# Stardw — 2D Изометрическая RPG на Godot 4.7 (Smooth HD Pixel-Art)

Полноценный проект на **Godot 4.7** с **изометрической 2:1 проекцией** (`TILE_SHAPE_ISOMETRIC`, ромбовидные тайлы `64×32 px` с 3D-фаской `64×40 px`), сглаженной текстурной фильтрацией (`LANCZOS` + `TEXTURE_FILTER_LINEAR` без режущих глаз ступенчатых пикселей), **17 разновидностями деревьев, скал, руды и объектов леса** и плавными **8-кадровыми анимациями** персонажа-исследователя без экипировки.

---

## Что реализовано и обновлено

### 1. Персонаж-Исследователь без экипировки (`assets/sprites/player_spritesheet.png`, `768×5376 px`)
- **Внешний вид**: Обычный путешественник-исследователь в простой походной одежде (светлая рубашка с закатанными рукавами, коричневый кожаный жилет, оливковые брюки, кожаные сапоги) — **без посоха, без рюкзака и без какой-либо экипировки**.
- **Плавные 8-кадровые анимации (56 рядов × 8 кадров `96×96 px`)**:
  - Все 7 состояний (`idle`, `walk`, `run`, `axe`, `pickaxe`, `water`, `interact`) по 8 изометрическим направлениям (`down`, `down_right`, `right`, `up_right`, `up`, `up_left`, `left`, `down_left`) имеют **по 8 плавных кадров**.
  - Вместо резких сдвигов используется непрерывная субпиксельная билинейная деформация (`bilinear_warp_rgba`) на 2× суперсэмплинге (`192×192 → 96×96` с фильтром `LANCZOS`).
- **Витрина всех направлений и состояний**: `assets/sprites/player_8dir_showcase.png` (`768×672 px`).

### 3. Мягкий сглаженный пиксель-арт без резких пикселей (`tools/build_isometric_assets.py`, `project.godot`)
- Отказ от жёсткого `NEAREST` даунскейла и шумного попиксельного дизеринга: все спрайты и изометрические тайлы (`assets/tilesets/world_tileset.png`, `1024×200 px`, 5 рядов × 16 колонок) рендерятся с 2× суперсэмплингом и уменьшаются с антиалиасингом `Image.Resampling.LANCZOS`.
- В `project.godot` и во всех сценах (`player.tscn`, `world_object.tscn`, `world.tscn`) включена линейная фильтрация текстур (`default_texture_filter=1`, `texture_filter = 2`) и плавное субпиксельное движение без рывков.

## Управление в Godot 4.7

| Клавиша | Действие |
|---|---|
| `WASD` / `Стрелки` | Ходьба по 8 изометрическим направлениям |
| `Shift` (удерживать) | Бег (`run`) |
| `Пробел` / `ЛКМ` | Использовать выбранный инструмент (`1` — Топор, `2` — Кирка, `3` — Лейка, `4` — Сбор) |
| `E` / `F` | Действие сбора / осмотра (`interact`) |
| `R` | Сгенерировать новый изометрический мир по новому сиду |
| `C` / `F3` | Показать / скрыть изометрические коллизии воды, деревьев, камней и персонажа |
